# EasyPub Modern v1.56.0

本次将 v1.22.0 之后的本地支线改动集中同步到 GitHub，包含参考目录修复、书源管理、章节核对、长篇提醒整理与原稿保护。

## 下载与使用

- 安装版：`EasyPubModern-Setup-v1.56.0-x64.exe`
- 便携版：`EasyPubModern-v1.56.0-reviewable-repair-win-x64.zip`，完整解压后运行 `EasyPub.Desktop.exe`。
- Windows x64；两种包均包含运行环境和 KindleGen 2.9。旧版项目可以继续打开。

## 主要更新

- **参考目录修复**：获取公开目录、定位真实源标题，再核对并应用。目录未匹配不直接等于源文件缺失，不补造章节正文。
- **可检查的应用结果**：展示新增/移除章节、标题、顺序、层级和正文范围的完整实际变化。未勾选的目录外标题不再被隐式并回正文。
- **保护手工整理**：手工标题默认保留；保留手动排序、层级、正文范围和无原文标题行的拆分章节。参考目录不会自动重建手工树的卷结构。
- **备份与清单**：删除重复正文和清理重复标题前，确保原稿快照与逐行移除清单。操作仍可撤销。
- **成品变更记录**：TXT 转换采用章节树或发生文本清理时，在成品旁生成 `EasyPub-变更记录`，包含源文件备份、哈希、取文范围、逐行清理变化和完成后的成品哈希。
- **核对状态保存**：参考目录来源及已确认提醒随项目保存；相关原文或章节发生变化时重新提示。目录获取可取消，已有目录可查看、更换和刷新。
- **提醒整理**：编号跨度很大的位置集中到“编号差异”入口，同层级编号顺序提醒合并一组，保留全部位置供定位核对。断点对齐在后台执行。
- **兼容性修复**：修复“零＋单位”的中文章号解析错误和空缺口列表导致的工作台崩溃。
- **外置编辑副本**：主界面和章节工作台创建独立 TXT 副本后再打开编辑器，原始书稿保持不变。
