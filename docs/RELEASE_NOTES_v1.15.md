# EasyPub Modern v1.15

本版集中完成书库工作流、章节与文本清理入口以及界面一致性的收尾。

- 书库中的单击、Ctrl 多选、拖选、右键批量操作和“仅转换所选”形成一致选择逻辑。
- 所选书稿区域改为独立卡片，封面、书籍状态与三个常用编辑入口保持紧凑可见。
- 章节结构与文本清理保留为就地弹窗，避免频繁切换页面；独立“章节正文”导航已移除。
- 封面信息页可以独立选择要编辑的书籍，不再强制跟随书库当前项。
- 修复自定义文本清理规则的启用状态绑定、切换保存、作用范围统计和规则导入状态。
- 延续 Kindle 设备预览、图片兼容处理、原版 config.xml 映射、批量元数据和成品验收能力。

发布内容包含 Windows x64 安装包和免安装便携包。
