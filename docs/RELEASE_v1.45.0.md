# EasyPub Modern v1.45.0：章节修复与完整性验证

日期：2026-09-15。基于独立支线 v1.44.0；原仓库未修改，未提交或推送 GitHub。

## 运行

便携目录：`outputs/EasyPubModern-v1.45.0-repair-integrity-win-x64/`。
运行其中 `EasyPub.Desktop.exe`，保留同目录的 `config.xml` 和 `bin/kindlegen_v2.9.exe`。
对应 ZIP 和安装包位于 `outputs/`。无需安装 .NET SDK。

## 推荐流程

1. 添加 TXT，进入章节工作台。
2. 点击「一键修复」。它使用当前章节树、本书保存的目录；番茄书稿会尝试匹配同目录下载记录的准确书名与编号。
3. 获取不到目录时，进入「目录辅助修复」，填写书籍网址或番茄编号，也可以导入目录文字。每行一个标题，卷标题也保留。
4. 核对参考来源和调整方案。未定位不等于原文确实缺失：可能是标题不同、目录更新、用户先前删除或原文本身不完整。
5. 应用后检查目录及预览；不满意使用撤销。需要手动去重时，在目录调整窗口选择项目，查看原文片段后决定。
6. 转换输出 EPUB/MOBI。设备显示仍需实机验收。

## 修复内容与证据

| v1.44.0 问题 | v1.45.0 行为 |
| --- | --- |
| 无编号目录外标题被跳过，正文也丢失 | 先移除标题边界再分配正文；非章节内容并回正文；逐行核对覆盖 |
| 重建恢复先前删除的内容 | 当前章节树的覆盖范围是输入边界；不从完整 TXT 重新填入已删除行 |
| 一键修复忽略当前编辑状态 | 传入当前树快照，保留现有范围和编辑属性 |
| 同名不同正文默认删除 | 默认仅删除忽略空白后正文相同的重复项；不同正文保留供人工核对 |
| 移除清单只有标题行 | 保存实际移除的全部标题与正文行，以及源路径、SHA-256；文件名唯一，不覆盖旧清单 |
| 预览阶段就写入清单 | 方案准备不写备份／移除文件，确认应用时才写入 |
| 缺章通过标题集合判断 | 按参考章节的独立定位行逐个计数，跨卷同名不能冒充另一章 |
| 无目录时误重建／推断完整性 | 保留当前树，明确无法判断完整性，并提供目录入口 |
| 未取得目录时缺少下一步 | 明示网址、编号、导入目录；有准确下载记录的番茄书稿可直接解析来源 |
| 导入目录丢失分卷 | 保留卷标题和每章归属；参考分卷统一排列，避免重复生成同名卷 |
| 已识别章节被再次漏掉 | 定位器复用当前标题位置，不再要求它们附近必须有空行 |
| 相似标题被误报为重复 | 重复候选要求标准化标题一致，并且确实是当前章节节点；另一参考章占用的行不当作重复 |
| 正文中提到章号也被当标题 | 未知候选增加标题行形态约束，保留三位数字冒号等真实标题形式 |
| UI 冻结、不能取消 | 计算转入后台，提供取消；应用前展示完整的未定位列表及待核对数量 |
| 目录入口提示互相矛盾 | 输入有明确标签，登录统一进入书源设置，未取得目录时禁用调整，内容可滚动 |
| 去重说明说正文不变或并入前章 | 明确从成品移除所选重复内容，原 TXT 不变，应用前有备份与逐行清单 |
| 全局起点 Cookie 可能发到其他站点 | Cookie 按域名限定，跨域候选不继承，HTTP 不发送 Cookie |
| 域名可解析到内网／IPv4 映射绕过 | 连接时验证 DNS 地址并连接已验证 IP，拒绝本地、私有和映射地址 |

首次原文备份继续保留，修复前额外按内容哈希保存快照。源码检查到原文已变化时停止应用。
移除清单位于 `%LOCALAPPDATA%/EasyPub Modern/SourceBackups/Removed`，可通过结果中的完整路径找到。

## 保留的能力边界与待验收项

- Kindle 真机显示、目录点击、跨卷跳转：用户确认暂时没有设备，先交付并列为待验收。EPUB 解析或软件预览不等于实机验证。
- 番茄独立关键词搜索：未实现。产品支持准确网址／编号及同目录准确下载记录，目录文字也可导入。不宣称任意书名都能搜索成功。
- 自动换源下载缺失正文：未实现，保持目录修复工具的范围；参考目录不是正文来源。
- 部分真实书稿仍有未定位章节、目录外章节或待核对重复，不掩盖成「完全修复」。依据报告逐项核对。
- 第三方书源可能限流、登录受限或变更。Cookie、网址和本地目录导入作为明确入口；本次不宣称所有站点始终可用。
- DNS 安全连接使用直接连接，不使用系统 HTTP 代理；仅代理可联网的环境需要另外适配。
- 原版 `HANDOFF.md` 和早期版本文档作为历史证据保留；其中 v1.44.0 行为、测试数量及备份口径由本说明更新。旧 v1.22.1/v1.22.2 文档提到的产物不存在，不应当作交付入口。
- GitHub 仍是旧发布：本次仅本地交付，没有提交、推送或创建远程 Release。
