# EasyPub Modern v1.22.0

本版完成章节工作台、数字章节识别和长篇 TXT 工作流的收口，重点是让“识别结果、用户修正和最终保存状态”清楚可追踪，同时减少打开长篇小说时的等待。

## 下载

- 便携版：`EasyPubModern-v1.22.0-win-x64.zip`
- 解压后运行 `EasyPub.Desktop.exe`；请保留同目录的 `config.xml` 和 `bin` 文件夹。
- 便携包包含 `bin/kindlegen_v2.9.exe`，MOBI 转换仍需遵守 KindleGen 的兼容边界。
- SHA-256：`330D26148E7352EA445AE5E87BF01622E0A77B9358C0EDCA29B08FC0C3DC9665`

## 主要变化

### 章节工作台

- “全部章节 / 待核对”统一为同组分段筛选，保持选择状态清晰。
- 增加章节问题分类、上一处/下一处、原文定位和当前组导航。
- 支持 Ctrl 多选、Shift 连选，以及按连续区段批量归入上一章。
- 原始标题、成品标题和正文原文分开展示，处理后可撤销。
- 重复标题清理支持默认 0 行标题和自定义行数范围。

### 数字章节识别

- 对没有识别到普通章节的书稿，提示疑似 `001：标题`、`002：标题` 等数字章节。
- 识别前由用户确认，不会因为打开书稿而自动改变其他书。
- 可选择规范成品标题，或保留原始数字标题；两者都不回写原始 TXT。
- 支持全局默认规则、逐书覆盖和多个命名识别方案。
- 书库状态明确区分“已保存章节树”和“已识别但未保存”。

### 长文本与编辑器

- 章节识别、正文预览和转换前检查共享文档缓存，避免重复读取和解析。
- 章节树和正文预览启用虚拟化，降低长篇小说打开和切换时的卡顿。
- 支持配置 Notepad3 等外部文本编辑器；源文件变化后会重新检查旧章节树是否有效。

## 已知边界

- 章节识别仍需用户核对，自动识别结果不等于最终目录方案。
- 便携包不替代 Kindle 真机验收；复杂 EPUB、固定版式、特殊字体和 DRM 内容仍受既有兼容边界限制。
