# EasyPub Modern v1.1.1

这是针对 v1.1.0 用户反馈的修复版本。

## 修复与改进

- 修复打开文本清理时可能出现的 `StaticResourceExtension` 资源解析异常。
- 文本清理规则管理窗口和快捷键管理窗口改为使用各自明确声明的统一样式，不再依赖主窗口局部资源。
- Kindle 书页预览新增上一页、下一页与页码，并按所选设备尺寸、字体、行高和页边距重新估算分页。
- 预览会从识别出的首章正文开始，不再把书名、作者和网站信息当作章节正文。
- 主界面左侧新增可见的“快捷键管理”入口。
- 清理设置页重复的 GitHub 项目按钮。

## 验证

- 自动化测试覆盖文本清理窗口、快捷键窗口与多页 Kindle 预览。
- 发布包会再次执行真实桌面操作验证：导入 TXT、打开文本清理、打开快捷键管理、切换预览页。
