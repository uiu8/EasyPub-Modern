# EasyPub Modern v1.46.0

## 本次交付

按选定的第 1、3 项实施：统一标题识别基础规则，简化章节工作台入口与规则说明。基于 v1.45.0，未改动原始开发仓库，未发布到 GitHub。

### 标题识别

- 普通章节、卷章层级和参考目录候选共用 HeadingSyntax 的数字字符与标题边界。
- 支持缺少“第”的编号标题、全角数字、大写中文数字；独立的序章、前言、番外、尾声等需要结尾或明显分隔符。
- 修复参考目录中阿拉伯数字章号未解析、逐字中文数字“一一〇”解析错误；章节诊断也使用同一数字转换。
- “三回头看”“三回到家里”“前言不搭后语”“正文开始了”等句子不会被内置标题规则升级成章节。
- 自定义表达式仍优先。已保存的章节树不会自动重建。旧项目若明确保存旧表达式，可在识别设置中恢复默认，再预览重新识别。
- 明确使用 LegacyDefault 的原版兼容调用保留旧表达式；原版 EPUB/MOBI 黄金样本保持通过。桌面新建配置使用新的内置规则。

### 操作流程

1. 查看“待核对”问题。
2. “预览目录修复”自动准备方案，核对后应用；需要更换来源或逐项核对时使用“手动核对目录”。
3. 结构整理、重复标题等集中在“整理工具”，结构异常仍会提供直接入口。
4. 在“识别设置”查看下次识别使用的规则、数字规则范围、是否存在尚未套用的修改。未启用分层时，相应表达式不可编辑。
5. “保留设置”不会重建当前树；“按当前规则重新识别”替换当前树并支持撤销；最后“应用并返回”提交工作台修改。

## 已知边界与待验收

- 没有 Kindle 真机；设备中的目录点击、层级显示、简体中文和翻页行为待用户接机验收。
- 标题识别仍是规则判断，不能保证所有自然语言标题无误。新增支持可能增加目录条目，请先核对预览。
- 无编号标题仍需参考目录及上下文；此次没有加入英文 Roman 章号或词典保护功能。
- 目录未定位项仍须核对原文；软件不自动补下载缺失正文。番茄独立关键词搜索仍未实现。
- 参考源访问沿用 v1.45.0 的直连策略，不使用系统 HTTP 代理。
- 安装包已构建，但未覆盖安装现有版本。

设计参考：novel-processor 的标题边界与渐进展示思路（审阅版本 58e3fb9）。本次使用 C# 独立实现，没有引入其运行时依赖。
