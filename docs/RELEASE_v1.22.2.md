# EasyPub Modern v1.22.2

修复文本清理记录仍限制单选的问题。支持 Ctrl 多选、Shift 连选，并提供“采用所选”和“保留所选原文”批量操作；重新分析后保留操作选择。折叠记录的批量操作覆盖组内各处。

清理预览默认显示“清理后”，可以切回“原文”比较。选择记录不再抢走列表键盘焦点。应用规则保存转换清理设置，原始 TXT 不变；自动检查中的“已计划清理”表示转换时将处理。

修复连续修改规则后立即应用可能接受旧预览的问题：规则修改立即使旧分析失效，提交等待最新结果完成。

基于当前 v1.22.1 工作区继续修复，保留章节树性能与其他已有改动。提供独立命名的便携包及安装包。
