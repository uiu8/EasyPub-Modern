# EasyPub Modern v1.63.1

完整解压便携包后，双击 `EasyPub.Desktop.exe`；也可运行 Setup 安装。无需另装 .NET。

## 本版变化

- 章节工作台是独立弹窗，已移除重复的主流程左栏，让章节树、待核对问题、证据与原文获得完整宽度。
- 保留顶部“检查依据 × 应用范围”和底部撤销、重做、取消、“应用并返回”。主窗口的导航、配色和底部栏保持原有布局。
- 包含此前的章节修复、人工切分、章节移位、项目保存恢复及 Kindling 可选转换引擎功能。
- 整体优化计划属于后续开发安排，不等于本版已经完成全部优化。

## 使用 Kindling

打开转换设置，在“MOBI / Kindle”中将“Kindle 转换引擎”选为“Kindling（兼容 MOBI）”，再应用设置。

输出格式选择 MOBI。Kindling 程序路径留空即可使用包内的 `bin/kindling-cli-windows.exe`。KindleGen 仍是默认引擎，已有用户设置继续保留；EPUB 输出不受此选择影响。

TXT 转换使用已确认的章节树生成中间 EPUB；EPUB 输入继续支持保留版式或兼容重排。转换失败时会提供日志路径，不会静默换用另一个引擎。

Kindling 不使用 KindleGen 的压缩级别、额外参数、ASIN/EBOK 和正文分片选项，相关设置会置灰。输出目录保留 Kindling 日志；许可证见 `bin/Kindling-LICENSE.txt`。

## 章节修复路径

1. 导入书稿，从“检查与修复”打开章节工作台。
2. 没有参考目录时选择“当前书稿”；有目录时先选择并核对目录来源。
3. 选择应用范围。默认仅整理成品章节树；文本操作必须先核对目标路径、差异与备份说明，建议使用修订副本。
4. 点击“检查章节”生成建议，再选择问题组查看原文证据和处理方式。
5. 预览后应用，保存项目；后续进入制作设置和转换验收。

缺失正文如实报告，不会为了凑齐目录生成空章。无标题且边界不明确的正文需要人工切分；只整理章节树不会让原始 TXT 的正则识别结果自动改变。
