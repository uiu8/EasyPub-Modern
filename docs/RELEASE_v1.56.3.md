# EasyPub Modern v1.56.3：侧栏文字遮挡修复

2026-09-16，基于 v1.56.2（53e1275）。

## 修复

侧栏“转换记录与验收”在正常宽度下超出内容区；窄窗口及紧凑密度也有导航文字溢出。旧模板使用横向 StackPanel，文字按不受约束的宽度排布；固定侧栏宽度扣除图标和内边距后不足。此前调整图标和父容器对齐没有解决这一点。

- 导航模板改为图标 Auto 列、文字剩余宽度列，文字必要时可换行。
- 所有侧栏导航左右内边距统一从 18 调整为 12，保留图标与文字对齐。
- 紧凑密度下的完整侧栏从 166 调整为 176；窄窗口仍为 132，默认侧栏仍为 184。
- 两处响应式布局入口使用相同的宽度规则。
