# EasyPub Modern v1.22.1

本版基于 v1.22.0 章节工作台版本，重点修复文本清理规则的多选和应用体验。

## 下载

- 便携版：`EasyPubModern-v1.22.1-cleanup-rules-win-x64.zip`
- 安装版：`EasyPubModern-Setup-v1.22.1-x64.exe`
- 便携版解压后运行 `EasyPub.Desktop.exe`；请保留同目录的 `config.xml` 和 `bin` 文件夹。

## 修复内容

- 清理页的广告清理及其他内置规则可以连续多选。
- 连续勾选会合并预览分析，避免每点击一次都触发一次完整分析。
- 预览分析进行时点击“应用规则”会等待当前分析完成并自动提交，不再静默无效。
- 预览失败时保持窗口打开并提示错误，不会把无效规则提交到书稿配置。
- 保存逐书独立清理规则后，章节页会立即显示当前书稿实际使用的规则范围。
- 原始 TXT 仍保持不变，规则只作用于转换副本。
