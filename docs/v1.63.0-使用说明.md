# EasyPub Modern v1.63.0

解压完整目录，双击 `EasyPub.Desktop.exe`。无需另装 .NET。

## 本版交付范围

- 章节工作台采用三栏核对布局：章节树、待核对问题、原文/参考目录证据；保留撤销、重做、取消和“应用并返回”。
- 参考目录与当前书稿是独立依据；“仅整理章节树”和“同时修改 TXT”是独立范围。原始 TXT 永不原地修改，修订副本会留下备份、项目和逐行清单。
- 卷名缺失、重复章节、跨卷移位、缺标题、真缺正文、缺“第”、纯数字标题和编号错字均按证据分流；真缺正文不会生成空章，歧义项必须人工确认。
- 本版已完成36格四组合全链验收，并用Kindling验证MOBI出口；47个本地语料文件完成只读识别与性能基线。

## 使用 Kindling

制作设置 → MOBI / Kindle → Kindle 转换引擎 → Kindling（兼容 MOBI）→ 应用。
输出格式选择 MOBI，按原流程转换。程序路径留空即可使用包内 `bin/kindling-cli-windows.exe`（0.45.6）。KindleGen 仍是默认引擎，可随时切回；EPUB 输出不受影响。

Kindling输出MOBI7+KF8，未开放AZW3。TXT会使用当前确认的章节树生成中间EPUB；EPUB输入沿用保留版式/兼容重排选择。原稿不变。引擎失败会报告日志路径，不静默切换引擎。

“移除附加源文件”仍适用；压缩级别、ASIN/EBOK、KindleGen额外参数和正文分片优化不适用，界面会置灰。输出目录会保留 `*.kindling-*.log`。

面向本地阅读，不执行Kindling的KDP上架检查；仍保留EasyPub预检及Kindling正文自检。本版本不承诺KDP上架合规。

## 建议操作路径

1. 导入TXT或EPUB，先在“检查与修复”确认检查依据。
2. 有原目录时选择“参考目录”，没有目录时选择“当前书稿”；不要把目录存在误认为正文存在。
3. 先点问题卡查看证据和变更预览，再按需要选择“仅整理章节树”或“同时修改TXT”。
4. 需要改原文时使用“另存修订副本”或明确授权写回；应用前会创建备份和清单。
5. 保存项目并重开后再进入“转换与验收”，选择Kindling完成MOBI转换。

## 验证与限制

本版P5-1的36格全链转换均使用Kindling；P5-2实际47个物理TXT（42种唯一内容）均只读识别成功且源字节未改变。Kindle真机仍未验收，因为当前没有连接设备；请在有设备后检查实际目录、封面、字体和翻页行为。Kindling许可见 `bin/Kindling-LICENSE.txt`，项目：[ciscoriordan/kindling](https://github.com/ciscoriordan/kindling)。
