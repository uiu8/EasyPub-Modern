## 复现

在仓库根目录，设置 `$dotnet='D:\software\dotnet-sdk-10.0.302\dotnet.exe'`：

```powershell
# 默认执行，保留其失败记录
& $dotnet test tests/EasyPub.Core.Tests/EasyPub.Core.Tests.csproj -c Release --no-build --no-restore
# 同一程序集串行全量，排除测试间的并发竞争
& $dotnet test tests/EasyPub.Core.Tests/EasyPub.Core.Tests.csproj -c Release --no-build --no-restore -- xUnit.MaxParallelThreads=1
# WPF 按既有隔离策略执行并核对发现数与执行数
& ./tools/test-desktop-isolated.ps1
```

以上 --no-build 命令依赖当前快照已构建；首次使用先构建。桌面脚本自行构建并串行执行34组，测试发现与执行数量一致。
