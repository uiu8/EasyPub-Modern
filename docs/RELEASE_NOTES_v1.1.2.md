# EasyPub Modern v1.1.2

本版本修正 Kindle 书页预览中的段首缩进，并补齐原版 EasyPub 的可配置全角空格数量。

## 修复与改进

- 修复书页预览分页时调用 `Trim()`，导致段首 U+3000 全角空格被删除的问题。
- “保留两个全角空格”改为“全角空格缩进 × 数量”，可选择 0–20 个。
- 修改数量后书页预览立即重新分页并显示新的段首缩进。
- 全角空格数量写入转换方案和项目设置，并参与最终 EPUB/MOBI 正文生成。
- 导入原版 EasyPub `config.xml` 时直接采用 `addspacecount`，不再固定为两个。
- CLI 增加 `--fullwidth-indent-count 0..20`。

## 验证

- 验证 2 个与 3 个全角空格在预览中的显示和动态切换。
- 解包生成的 EPUB，确认每个正文段落实际写入配置数量的 U+3000。
- 验证原版配置中的 `addspacecount=4` 能完整导入。
