# EasyPub Modern v1.57.1：降低更新检查的请求频率

2026-09-16，基于 v1.57.0（1a543b3）。

## 修复

v1.57.0 的更新检查**每次启动都会请求一次** GitHub。GitHub 对未认证请求的限制约为
**60 次/小时/IP**，因此频繁重启软件、或多人共用同一个出口 IP 时会撞上限流，
界面上表现为「更新服务暂时限制了请求频率，请稍后再试。」——这是上一个版本实测到的限制。

现在两次**启动检查**之间至少间隔 **6 小时**：间隔内直接沿用上次查到的结果，不再发请求。

- 手动点「检查更新」**不受**这个间隔限制，随时可以强制查询。
- 缓存文件损坏、或时间戳异常（系统时间被往前调过）都会当作没有缓存，照常查询——
  不会因为一条坏记录就再也不检查更新。
- 已是最新的结果同样会被记下来（只是不带版本号），所以也不会反复请求。
- 记录位置：`%LOCALAPPDATA%\EasyPub Modern\update-check.json`。

## 验证
