# EasyPub Modern v1.63.1

本版将章节工作台恢复为专注章节修复的独立弹窗：移除重复的品牌和制作流程左栏，保留三栏核对区、顶部依据与应用范围、底部撤销/重做和“应用并返回”。主窗口继续使用原有导航、配色和底部栏。

## 从 GitHub v1.61.2 升级

本次同时发布此前本地交付的章节修复与 Kindling 集成：

- 当前书稿/参考目录与仅整理章节树/文本修订两条独立选择贯穿检查、预览和应用。
- 完整重复、连续重复标题、卷边界、章节移位、缺标题和编号写法分别提供证据与处理入口。
- 人工切分支持预览、当前规则校验和修订副本；保留撤销、备份及移除逐行清单。
- 真缺正文继续保留缺失报告，不自动补造空章；有歧义的归属或正文边界需人工确认。
- 新增 **Kindling 可选 MOBI 转换引擎**，安装包与便携包均内置引擎及许可证。KindleGen 默认值与现有用户设置保持兼容。

## 下载与使用

- 安装版：`EasyPubModern-Setup-v1.63.1-x64.exe`。
- 便携版：`EasyPubModern-v1.63.1-popup-shell-fix-kindling-win-x64.zip`，完整解压后运行 `EasyPub.Desktop.exe`。
- 均面向 Windows x64，自带 .NET 运行环境。
- 使用 Kindling：打开转换设置 → MOBI / Kindle → Kindle 转换引擎 → Kindling（兼容 MOBI）；路径留空使用包内引擎。

- 弹窗修正已通过 Desktop 定向 11 项、主窗口回归 63 项和 1 项工作台截图检查。
