# EasyPub Modern v1.16

本版正式加入超长小说转换优化、正文目录页控制和长篇编辑响应优化。

## 转换与目录

- 在章节树的“识别与层级规则”中增加“在正文开头生成目录页”，默认关闭。
- 关闭正文目录页后，不再把全部章节作为一页正文插在书前；Kindle 的“前往／目录”、章节跳转和分级关系继续由 NCX 保留。
- “转换输出 → 高级参数”增加“优化超长小说编译速度”。启用后会自适应合并底层正文文件，减少 KindleGen 的文件处理开销；逻辑章节、目录目标与章节分页保持不变。

## 长篇书稿响应

- 章节预览和章节树工作台共享同一份分析结果，避免对同一本书重复读取、哈希、解码和建树。
- 添加 TXT 后不再抢占后台资源自动保存默认章节树，首次需要时再按需识别。
- 章节树启用界面虚拟化，降低上千章节同时创建控件的开销。
- 文本清理窗口先显示，再在后台生成全文预览；用户可以立即看到分析状态，不再等待同步处理结束后才出现窗口。

## 验证

- 自动测试：EasyPub.Core.Tests 105 项、EasyPub.Desktop.Tests 33 项全部通过。
- 使用约 11.66 MB 的真实中文长篇验证：无正文目录页 EPUB 不包含 `book-toc.html`，NCX 仍保留 1393 个章节目标；优化转换成功生成有效联合 MOBI。
- Kindle 真机已验证优化模式未改变现有目录显示；不同设备上的最终分页和导航仍以实际阅读器结果为准。
