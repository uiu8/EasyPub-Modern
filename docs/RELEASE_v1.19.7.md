# EasyPub Modern v1.19.7

本版集中补齐自动检查、转换安全保护和界面交互细节，延续 EasyPub 增强版／电子书转换器的定位。

## 下载与升级

- 安装版：`EasyPubModern-Setup-v1.19.7-x64.exe`。
- 便携版：`EasyPubModern-v1.19.7-win-x64.zip`，完整解压后运行 `EasyPub.Desktop.exe`，保留 `bin` 文件夹。
- 建议升级前保存项目；便携版解压到新目录，不覆盖正在运行的旧版。
- 结构验收不代表所有 Kindle 型号均已实机验证；跨显示器 DPI 测试尚未完整覆盖。

## 本版新增与修复

- 导入后后台分析书稿，显示等待、分析中、建议处理、必须处理等状态，并提供问题处理入口。
- 自动检查可整体关闭，也可分别选择资源检查、全部内置文本清理规则、简繁转换和自定义规则；书库显示当前开启项。
- 区分待处理问题、已经安排转换时清理的内容和用户排除项；没有启用检查项目时不再暗示已全面检查。
- 打开清理预览时合并检查规则与现有清理配置，保留已有规则和设置；无效正则单独提示。
- 跨行清理可能破坏已保存章节树或按行定位插图时阻止不安全转换，而不是静默生成错位内容。
- EPUB 兼容重排对可能丢失的复杂结构和目录映射增加保护，提示改用保留原版式；这不是完整复杂 EPUB 重排支持。
- MOBI 输出通过临时文件写入并完成后替换目标，降低失败或取消留下半成品、损坏旧输出的风险。
- 成品结构验收失败不再计为成功，纳入失败与重试流程。
- 所选书稿支持滚动，滚动条改为细型样式；收藏导入及子菜单与应用主题统一。
- 修复可编辑下拉框缺少输入区的问题，分类和语言可以输入自定义内容。
- 修复按钮悬停对比度、深色主题文字和开关、选中页签导致正文继承加粗的问题。
- 窄窗口正确进入紧凑布局，搜索框不再被固定列宽挤扁；编辑转换设置时临时收起输出概览，关闭后恢复。
- 设置增加未应用修改提示及作用范围说明；保留底部格式、排版快捷入口和右侧封面区域。

## 验证

- 本地自动化回归：Core 131 项、Desktop 45 项，共 176 项通过。
- 发布版窗口标题与文件版本核对，启动响应、正常退出通过。
- 浅色窄窗口、深色常规窗口的五类转换设置已进行渲染检查。
- 仓库本次发布前没有配置 GitHub Actions；不将本地测试表述为云端 CI 通过。

## 与 v1.16 相比

以下以实际存在的 Git 标签 `v1.16` 为基线，包含 v1.17、v1.18 和本版累积改动；并非全部在 v1.19.7 首次加入。

| 方面 | v1.16 基础 | 升级后的变化 |
|---|---|---|
| 原始 TXT 编辑 | 以章节结构和清理配置为主 | 可调用外置编辑器；保存后重新读取并失效旧分析缓存 |
| 广告清理 | 较有限的句式识别 | 组合网址、推广语境等信号识别变体，并接入可选自动检查；仍需人工核对误报漏报 |
| Kindle 章节导航 | 已有正文目录页开关 | 新增可选章顶上一章／下一章；有正文目录页时显示目录链接，修复脚注弹窗和跳转落点问题；不等于调用 Kindle 原生目录面板 |
| 转换设置 | 选项分散在多个面板 | 统一五类设置，EPUB 模式可提前选择；明确本机引擎设置，增加草稿修改反馈 |
| 批量选择 | 原有批量转换 | 行首复选框独立多选与取消，右侧前后切书不改变转换范围 |
| 自动诊断 | 转换前检查与成品验收 | 导入后台分析、可配置检查规则、状态摘要和问题处理入口 |
| 转换安全 | 原有转换链路 | 源位置错位保护、复杂 EPUB 重排保护、MOBI 安全写入、验收失败正确统计 |
| 界面细节 | 原有现代化界面 | 细滚动条、主题菜单、输入控件修复、按钮与字体继承修复、窄窗口适配 |

v1.16 已有的超长小说合包优化、正文目录页开关、章节树和清理窗口性能改进，不重复算作此后新增。

核对依据：`git diff v1.16 v1.19.7`、各版本 README，以及 `AutomaticCheckTests`、`QualitySafetyTests`、`MainWindowLayoutTests` 等回归测试。用户路径：导入书稿 → 查看自动检查摘要 → 按需处理 → 调整转换设置 → 转换与验收。
