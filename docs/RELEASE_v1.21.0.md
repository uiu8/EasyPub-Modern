# EasyPub Modern v1.21.0

本版集中整理文本清理的审阅、规则编辑和重复项处理，不改变 Kindle 章节导航实现。清理规则在转换时生效，不直接修改原始 TXT。

## 如何使用

1. 打开书稿的“文本清理”，选择检测记录；默认查看原文上下文，不必先排除修改才能判断是否误报。
2. 只想保留这一处，点击“保留本处”；需要复用广告判断条件，打开当前广告规则入口，在独立窗口选择删除或保留，查看影响后保存。
3. 保存条件后即使检测记录消失，仍可通过底部“继续编辑”返回；也可以撤销刚才的条件修改。
4. 多条完全相同的修改可折叠为一组，显示次数，并支持整组保留、整组采用或展开逐处核对。此功能适用于全部内置规则和自定义规则。
5. 最后点击“应用规则”。默认保存为本书独立规则；需要复用时再展开作用范围，选择通用规则。已有其他书稿的独立规则不会被覆盖。

“完全相同”要求规则来源、修改前和修改后内容相同；同一网址但不同广告措辞、不同章节标题不会合并。不同 ID 的自定义规则即使同名，也不会混为一组。

## 主要变化（相对 v1.20.1）

- 广告删除和保留条件支持普通文字匹配，保留条件优先；保留原有正则和自定义能力。
- 内置规则支持编辑及恢复默认；恢复内置默认不删除独立自定义规则。
- 清理界面压缩常驻设置，按当前记录展示对应操作；统一原文/清理后上下文预览。
- 当前规则快捷入口准确定位内置或自定义规则，包括同名规则。
- 广告条件编辑改为独立窗口，自动分析影响；取消不会提交，快速输入的旧分析不会覆盖新结果。
- 全规则重复项折叠、组内查看及明确的删除/替换/保留数量。

## 验收依据与边界

2026-09-08，Windows x64，.NET SDK 10.0.302。本次在既有改动基础上新增大量记录回归测试；未增加新的清理算法。

| 证据 | 检查内容 | 结论 |
| --- | --- | --- |
| E1：解决方案自动测试 | 核心 141 项、桌面 53 项，包含规则 JSON 往返、逐书隔离、预检查、默认恢复、取消及撤销 | 全部通过 |
| E2：显式启用真实书稿测试 | 本地约 11.7 MB TXT 实际生成 EPUB，检查指定保留文本及源文件字节 | 通过；不会上传书稿或生成的小说 |
| E3：Large_cleanup_latest_options_win_and_group_choices_roundtrip | 4,000 条记录，连续 9 次切换，2,000 条同类修改折叠、整组保留并序列化恢复 | 通过；这不是不同硬件下的速度承诺 |

调用路径：书稿有效规则 → 清理预览/逐处选择 → 序列化保存 → 转换请求 → EPUB 正文。E1、E2 验证此路径的已覆盖案例；E3 验证界面重算和分组操作。自动测试不等同于所有书稿均无误报，用户仍应核对上下文。

复现命令（仓库根目录，需安装 .NET 10 SDK）：

```powershell
dotnet test -c Release --verbosity normal
# 将变量指定为自己的 UTF-8 长篇测试书稿；内容须包含默认规则能识别的广告。
$env:EASYPUB_CLEANUP_REAL_BOOK = 'D:\books\test-novel.txt'
dotnet test tests/EasyPub.Core.Tests -c Release --filter Optional_real_book --verbosity normal
```

真实书稿测试未设置环境变量时直接返回，不代表执行了真实转换；本次已单独设置变量运行。未进行新一轮 Kindle 真机验收，也未声称 MOBI 真机兼容性因此得到新增验证。

## 安装

发布 EXE 已通过本机启动检查：主窗口显示 v1.21.0、保持响应、正常关闭且退出码为 0。便携 ZIP 内 EXE 与发布目录 EXE 的 SHA-256 一致，并包含配置及 KindleGen。安装包已编译，但未覆盖安装到用户现有程序目录。

下载安装包运行，或将便携 ZIP 完整解压后运行其中的 `EasyPub.Desktop.exe`，不要只提取 EXE。建议保留旧版和项目备份，核对新版本后再清理旧版。
