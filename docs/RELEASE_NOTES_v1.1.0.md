# EasyPub Modern v1.1.0

本版完成黑白书页风格界面统一，并围绕批量转换、Kindle 预览、文本清理和真实用户操作补齐了完整工作流。

## 主要更新

- 批量并发支持自动调度以及 1、2、4、8、12、16、32 档位；MOBI 与 EPUB 会按资源和转换引擎分别限流。
- Kindle 预览新增 Paperwhite 3–6、基础款、Voyage、Oasis、Scribe、Colorsoft 与自定义分辨率。
- 文本清理新增不可见字符、异常 Unicode、重复章节标题、错误换行、重复页眉、OCR 替换等规则。
- 新增自定义文本或正则清理规则，支持作用范围、顺序、启停、逐项预览、导入导出和正则超时保护。
- 新增输出冲突策略、转换后自动打开目录、任务暂停/继续、快捷键管理、Ctrl 多选与拖拽框选。
- 新增封面与插图尺寸、格式和 Kindle 适配诊断；插图位置可视化并写入最终 EPUB/MOBI。
- 设置页可直接查看最新验收报告、打开报告目录和访问项目 GitHub。
- 统一主界面、设置和各功能弹窗的黑白书页式视觉风格。
- 发布包改为单文件自包含程序，并同时提供便携压缩包和 Windows 安装包。

## 验证

- 自动化测试：113 项全部通过。
- 安装包：静默安装、独立启动与关闭验证通过。
- 真实用户流程：导入 TXT、建立章节树、添加 WebP 插图、选择正文位置、生成 EPUB/MOBI、检查联合 MOBI7/KF8 结构全部通过。
- 成品检查：WebP 已转换为 Kindle 兼容 JPEG，1200×800 尺寸保留，图片真实位于设定的两段正文之间。

> 结构检查不能替代 Kindle 真机确认。首次使用新排版或新设备时，仍建议传入设备实际打开一次。
