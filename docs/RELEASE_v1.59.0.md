# EasyPub Modern v1.59.0

> 别名：chapter-repair　·　重点：目录修复的可信度与缺章分类

这一版几乎全部围绕「章节树与参考目录对齐」这件事。起因是一本人为构造的六卷缺陷样书：
六卷在原文里没有卷标题、第五卷 101–120 章三种写法都坏了、第一卷与第二卷有重复与错位副本、
第四卷有整段缺标题与整段缺正文、第六卷每章标题行出现两次。

用它反复跑两种修复模式，暴露出一批问题。这一版把它们逐个解决，并把样书与自测说明一起发布。

---

## 一、修复了「修复本身在骗人」

### 兜底定位不再跨段抓行（最重要）

旧行为：某章在原文里定位失败时，兜底扫描会**在全文范围内按章号取第一行**。当一本书分卷重新计数时，
这会把后面卷的章节行抓给前面卷——实测六卷样书上**41 章被错绑到别人的行**，而且全部报成「已定位」，
于是真正缺失的 43 章被掩盖成「已对齐 478/480」。

现在：兜底只在前一个与后一个**已定位章之间**搜索。找不到就如实报未定位。

| | 修复前 | 修复后 |
|---|---|---|
| 按章号错绑 | **41 章** | **0** |
| 报告未定位 | 2 章（真缺 43 章） | **43 章**（如实） |
| 定位率 | 478/480（99.6%，掺假） | 437/480（91.0%，真实） |

### 缺章拆成三类，不再混为一谈

「参考目录有、章节树没有」过去只有一种说法。现在分开报：

- **补齐漏识别**：原文里有这一行，只是没被识别 → 可直接收录（默认勾选）
- **疑似标题行（需你确认）**：这一段有正文、没有标题 → 给一行候选，**默认不勾选**，勾选后以该行为标题、正文一行不动
- **正文缺失（需人工核对）**：只报告，不可勾选。并区分两种原因——「这一段找不到它的标题，内容目前计入其他章节」（多为重复拼接）与「标题正文都没有」（文件确实不完整）

### 用目录标题词反查标题

比「这一行像不像标题」更锐利的判据：目录说这章叫「归途」，那一段里哪一行含「归途」。
文字完全一致时按「补齐漏识别」收录并预勾选；部分相符时列为「待确认标题行」。
六卷样书上因此多救回 2 章（标题完整存在、仅定位窗口没够到）。

### 复核面板与转换前检查也看得到缺章

修完之后打开的复核面板，过去只跑基于章号的诊断，于是「41 章缺失」被显示成「2 处编号断点」。
现在两处都接收参考目录，会明确报出「参考目录里有 N 章在章节树中没有」。

## 二、识别层的三处修正

| 问题 | 现象 | 修正 |
|---|---|---|
| 正文被当成标题 | 正文里以章号开头的句子（「第二章的内容他记不清了。」）被收成章节，把一章腰斩成两章 | 同时满足「含句末标点」且「长度 > 10」的才算句子，两个条件缺一不可（「第三章 谁在那里？」仍是标题） |
| 标题行连续重复 | 每章标题行出现两次 → 两个同名条目，第一个还是空章；六卷样书产生 200 条目、100 组重复 | 紧邻且完全相同的标题行只收一行，重复那行留在正文范围里，原文一行不丢 |
| 卷标题行混进候选集 | 「第一卷 初入江湖」被读成章号 1 + 标题词，与目录里同号章互相当成重复 | 收集候选行时跳过节标题行 |

实测（六卷样书）：实章 567 → 467，同名重复组 100 → 0，目录外条目 100 → 0。

## 三、自助修复的参数可调

「章节复核」面板新增**补建范围…**，可调：

- 两章之间最多补几章（默认 30）——分卷重新计数会造成巨大的假缺口
- 是否只认独立成行的标题
- 是否允许按纠错表纠正章号错字（如「第一百零久章」）
- 是否允许标题缺少「第」字

并修掉三处把补建器挡在门外的正则问题：缺口上限硬编码、单位与标题之间的空格被强制要求、
取消孤行要求时用整行长度判断标题。

---

## 四、跨标题重复检测

同一段正文出现在两个**不同标题**下时，过去查不出来（同名比较看不见它）。
新增检测，结果并入复核面板与修复报告。只报告、不自动删除。

> 性能说明：第一版实现按「长度 + 采样」分桶后两两比较，8000 章的书要 241ms 并吃掉转换前检查的
> 400ms 预算。现改为按正文文本精确分组 + 每组上限 32 章，241ms → 1ms。

---

## 五、顺序异常有了出口

副本与缺失会让某些章在原文里的位置与目录顺序相反，成品按原文位置排列，顺序因此与目录不一致。
过去这件事**没有任何提示**。现在报告首行给出「顺序异常（需人工核对）」，附原因与例子（六卷样书 31 处）。

## 六、界面修正

- 修复确认窗的统计卡片文案原本是「处并回」「章需你核对」，单位折进标签、动词丢了宾语，
  读出来是「1 处并回」。改为「数 + 单位」在上、完整标签在下。
- 新增截图测试：把确认窗与工作台渲染成 PNG，让「人看到的东西」也可核对——
  上述文案问题正是靠看图发现的，447 条断言没有一条能抓到它。

## 下一版方向

允许修改原文。设计方案已随仓库发布（`docs/2026-09-16_修复流程重构设计方案.md`）：
把「是否改变原文」做成选项，修复计划只算一次、落地分两种（只改章节树 / 压实写回 TXT，写回前
统一备份）。四卷样书上第四卷 30–40 那 11 章「标题行不存在」在编辑模型下只需插入 11 行标题即可解决。
