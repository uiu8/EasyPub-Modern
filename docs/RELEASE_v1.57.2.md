# EasyPub Modern v1.57.2：修正备份目录的命名

2026-09-16，基于 v1.57.1（5732148）。

## 修复

更新时为原程序文件做的备份，目录名此前用的是**要更新到的版本**，而不是**被替换掉的版本**。

真实更新验证里看到的正是这样：从 1.57.0 更新到 1.57.1 之后，备份目录叫 `.backup-1.57.1`，
可里面装的明明是 1.57.0。备份存在的意义就是回滚时辨认"更新前是什么"，这个名字把信息写反了。

现在备份目录按**被替换掉的版本**命名：从 1.57.1 更新到 1.57.2 会得到 `.backup-1.57.1`。

顺带把 `UpdateInstaller.CreatePlan` 的参数名从 `currentVersion` 改成 `replacedVersion`——
原来的名字正是让人传错值的原因。

## 这是怎么发现的

v1.57.1 发布后，用**真实的 v1.57.0 便携版**在沙盒里跑了一次完整更新：启动 → 正常关闭 →
自动覆盖 → 重启。版本确实从 1.57.0 变成了 1.57.1，落地日志也齐全，但备份目录名不对。

功能没坏（备份内容正确、更新成功、用户文件保留），所以单元测试和之前的验证都没碰到它——
**只有看真实的目录清单才会发现**。

## 验证

- Core 测试 **401/401**。
- Desktop 测试 **123/123**。
- 本次发布后同样用真实程序跑了一次完整更新闭环，确认备份目录名为 `.backup-1.57.1`。
