# EasyPub Modern v1.62.0

解压完整目录，双击 EasyPub.Desktop.exe。无需另装 .NET。

## 使用 Kindling

制作设置 → MOBI / Kindle → Kindle 转换引擎 → Kindling（实验性 · 兼容 MOBI）→ 应用。
输出格式选择 MOBI，按原流程转换。程序路径留空即可使用包内 bin/kindling-cli-windows.exe（0.45.6）。KindleGen 仍是默认引擎，可随时切回；EPUB 输出不受影响。

Kindling 首版输出 MOBI7+KF8，未开放 AZW3。TXT 会使用当前确认的章节树生成中间 EPUB；EPUB 输入沿用保留版式/兼容重排选择。原稿不变。引擎路径与选择跟随转换配置保存。

“移除附加源文件”仍适用；压缩级别、ASIN/EBOK、KindleGen 额外参数和正文分片优化不适用，界面会置灰。引擎失败会报告日志路径，不静默切换引擎。输出目录保留 *.kindling-*.log。

面向本地阅读，不执行 Kindling 的 KDP 上架检查（它会拒绝没有封面的书），保留 EasyPub 预检及 Kindling 正文自检。本版本不承诺 KDP 上架合规。

## 章节编辑进展

包含人工切分预览、按当前识别规则检查新标题、可选另存带标题的 TXT 副本及配套章节项目。继续编辑副本时请打开生成的 .easypubproj。原始 TXT 不变；当前窗口撤销不会删除已导出的副本。

重复章节按正文证据区分：短诗/正文提及标题不会被当作空章；整章副本需要用户选择后处理。本次仅完成相关反例收尾，全部章节重构仍在进行。
