# EasyPub Modern v1.20.1

保留文本清理规则定制功能，取消首次使用引导。相较本地测试版 v1.20.0，已移除引导窗口、自动弹出逻辑、设置入口和独立教程示例；不会再弹出教程。旧设置中残留的引导标记可兼容读取，无需手动删除配置。

## 文本清理规则

- 在“文本清理 → 内置规则自定义 / 恢复默认”调整内置规则：保留算法并补充替换，或仅运行自定义替换。
- 广告检测支持普通文本／正则匹配、网址推广组合识别及保留条件；预览显示命中依据，可逐项排除。
- 支持恢复本条、全部内置规则默认；保留独立自定义规则和勾选状态。关闭所有规则不会删除自定义配置。
- 默认仅保存当前书稿规则；可显式应用为项目通用规则并保存为下次默认，已有其他书稿独立覆盖不受影响。
- 本书可恢复继承通用规则；逐书覆盖随项目保存，自动检查使用同一套内置匹配定义。
- 清理在转换时处理，不修改原始 TXT。保留条件仅豁免广告算法，其他已开启规则仍可能处理该行。

## 下载与验证

- 安装版：`EasyPubModern-Setup-v1.20.1-x64.exe`。
- 便携版：`EasyPubModern-v1.20.1-win-x64.zip`。完整解压后运行 `EasyPub.Desktop.exe`，保留 `bin` 文件夹。
- 本地回归、真实 EPUB 自定义广告清理与源文件不变测试，以及发布包启动验证；未新增 Kindle 真机验证。
- 核对源码：`BuiltinCleanupOverride`、`TextCleanupPipeline`、`CleanupCustomizationTests`、`MainWindowLayoutTests`。GitHub Actions 尚未配置，不把本地测试称为云端 CI。
