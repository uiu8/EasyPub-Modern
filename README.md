# EasyPub Modern

以 EasyPub v1.50 为兼容基准的 Windows 批量电子书转换器，现已支持 TXT → EPUB、TXT → MOBI 与 EPUB → MOBI。

v0.20.0 完成第二轮用户体验优化：相同书稿和选项可直接复用最近一次转换前检查；任务中心改为默认不自动弹出并提供持久化开关；文件列表旁新增所选书籍概览；八个设置分页会显示修改标记，手动调整排版时自动切换为自定义模式；补充键盘快捷键、焦点边框和辅助工具名称；840px 窄窗口会自动压缩标题、按钮、预设和封面概览区域。界面同时直接解释原版兼容、现代排版、自定义三种排版模式的精确参数与作用范围。

v0.19.3 修复“高级”分页内容撑宽主界面后，焦点控件触发横向自动滚动、导致左侧标题和表单被截断的问题；同时取消转换选项区域的固定高度，避免最下面的结构验收开关被裁切。主工作区现在只进行纵向滚动，并通过真实窗口布局回归测试覆盖 840、1180、1750 三种宽度。

v0.19.2 将转换后结构验收改为默认关闭的可选功能，普通转换不再承担验收耗时。开启后，报告统一写入输出目录下独立的 `EasyPub-验收报告` 文件夹，按时间分别保存，默认只保留最新 10 条，也可选择保留 5、20 或 50 条；任务中心会明确标记未启用验收。开关和保留数量会随预设、项目及应用设置保存。

v0.19.1 修复打开“任务与验收”时，任务进度条尝试向只读 `Progress` 属性回写而导致转换失败的问题。任务中心所有展示字段现已统一为单向绑定，并增加真实窗口打开回归测试。

v0.19.0 新增逐书任务与成品验收中心：批量转换会分别显示等待、检查、生成 EPUB/MOBI、验收和完成/提醒/失败状态，并可查看问题、重试或打开输出目录；每本成品自动生成 `.easypub-report.json`，检查 EPUB 目录、图片、字体、链接、元数据，以及 MOBI 联合格式、ASIN/EBOK、KF8 边界与封面，并明确区分结构通过和 Kindle 真机确认。首页转换设置简化为“原版兼容 / 现代排版 / 自定义”三种模式，预设改为一个下拉框和独立管理窗口，正则、ASIN 与 KindleGen 参数移入高级分页。新增不改写源 TXT 的文本清理流水线，支持硬换行、连续空行、全角空格、数字章节、网站说明、简繁和中文标点处理，所有变化都可逐项预览并撤销。

v0.18.0 完成第一轮 UI 与体验重构：主界面支持高缩放和小屏滚动，底部检查/转换栏固定；自动恢复改为可恢复、暂不恢复或删除的页面内提示；文件、封面、预览、预设和转换按钮按当前选择自动启停；章节编辑与卷/章/节识别规则合并为章节工作台，并新增撤销、重做、快捷键和按规则重新识别。

v0.17.2 按用户决定取消 Kindle Previewer 外部联动：移除主界面与整书预览入口、外部程序发现/启动器、专用缓存接口及相关测试；保留本地整书 EPUB 预览，TXT/EPUB → MOBI 转换不受影响。

v0.17.1 修复 Kindle Previewer 只启动后台转换服务、没有显示预览窗口的问题：交互预览改为使用 Windows 安装器实际注册的“直接打开 EPUB”方式，不再向图形主程序附加 `-showpreview/-output/-locale`；已用中文书名真实验证出现可见 Kindle Previewer 窗口。

v0.17.0 新增 Kindle 格式预览：主界面可把 TXT 按当前设置生成同源 EPUB，或直接使用选中的 EPUB，并通过 Amazon Kindle Previewer 公开的 `-showpreview` 接口打开 Kindle E-reader、平板和手机模拟预览。整书窗口保留快速 EPUB 预览并提供官方预览按钮；自动发现本机 Previewer，未安装时提供官方下载入口，亦可手工选择其他 EPUB 阅读器。官方预览缓存独立保存七天，不覆盖原稿或正式输出。

v0.16.3 修正章节树选中项在移动过程中的界面重入问题：移出父章节不再复制父节点和后续章节，归入上一章也会始终移动原先选中的章节。新增真实 TreeView 操作回归测试。

v0.16.2 修正章节树层级逻辑：目录深度与正文标题样式分离，无卷章节现在是真正的根级目录；“提升”与“降低”改为明确的父子关系操作，只在可执行时启用，并保持正文顺序。旧项目会自动归一化，无需重建章节树。

v0.16.1 修正章节树前置内容：自动生成的“序”现在标记为“前置”根节点，不再显示为 L1，也不会把后续 L2 章节错误地收为子项；v0.16.0 已保存的章节树会自动迁移。

v0.16.0 新增 EPUB → MOBI，并提供“保留原 EPUB 版式”和“EasyPub 兼容重排”两种方式。前者把原书 CSS、图片和目录交给 KindleGen，后者读取 EPUB 阅读顺序、目录层级、正文、封面与插图，再套用 EasyPub 的版式设置。新增逐书章节树，可编辑标题、重排、拖拽层级、提升/降级、拆分、合并，以及决定章节是否进入 Kindle 目录；章节树随项目保存且不会改写原始 TXT。

> MOBI 转换需要 Amazon KindleGen 2.9。项目不会重新分发该程序；本机默认会发现原版 EasyPub 中的 `kindlegen_v2.9.exe`，也可以在桌面端或命令行中指定路径。

## 立即使用

解压发布包后运行 `EasyPub.Desktop.exe`：

1. 添加或拖放多个 TXT / EPUB。
2. 常用目录可点“添加收藏”；以后从下拉框选中后直接多选书稿。
3. 选择 EPUB 或 MOBI，再从“原版兼容 / 现代排版 / 自定义”选择一种模式；需要时可打开文本清理预览。
4. 点击“开始批量转换”，在“任务与验收”中查看每本书的状态和成品报告。

### 三种排版模式

三种模式只是正文排版参数的快捷方案，TXT → EPUB、TXT → MOBI 仍使用同一套 EasyPub 兼容生成流程。它们不会替换封面、书籍信息、插图、章节树、字体、定制 CSS、KindleGen、ASIN 或结构验收设置。

| 模式 | 字号 | 行高 | 段间距 | 首行缩进 | 上/下/左/右边距 | 对齐 | 两个全角空格 |
|---|---:|---:|---:|---:|---|---|---|
| 原版兼容 | 110% | 120% | 0.6em | 0em | 0/0/3/3px | 默认 | 保留 |
| 现代排版 | 105% | 165% | 0.35em | 2em | 12/12/18/18px | 两端对齐 | 不额外添加 |
| 自定义 | 使用当前值 | 使用当前值 | 使用当前值 | 使用当前值 | 使用当前值 | 使用当前值 | 使用当前值 |

“原版兼容”适合希望尽量复现 EasyPub v1.50 正文密度与段落处理的书稿；“现代排版”留白和行距更大，适合高分辨率 Kindle；“自定义”不主动改值，适合在任一方案基础上微调。手动编辑版式分页或“保留原版每段两个全角空格”后，程序会自动切换为自定义，避免模式名称和实际数值不一致。

分页标题后的 `●` 表示本页有尚未写入命名预设的修改。蓝色说明属于整批通用设置；封面、逐书信息、插图和章节树按选中的小说分别保存。

如果希望从某个来源目录导入的书自动标记出版社，可打开“书籍信息”分页，点击“文件夹元数据映射”，添加该目录并把出版社填写为“起点”。以后从该目录导入的书会显示绿色元数据标记，转换后的 EPUB/MOBI 会写入对应出版社；在“批量编辑逐书信息”中可以检查或手动覆盖。

标题栏“项目”菜单可以保存或打开 `.easypubproj`。项目文件相当于一份可继续工作的任务档案，包含书稿列表、逐书信息、封面、插图、输出目录、层级目录规则和其他转换选项；工作中每两秒原子写入一次本地恢复快照，异常退出后下次启动会询问是否恢复。

要使用层级目录，请打开“章节”分页，点击“层级目录设置”并启用。默认会把“第一卷”识别为一级、“第一章”识别为二级、“第一节”识别为三级；若小说使用“PART / CHAPTER / SECTION”等格式，可在同一窗口修改三条正则。

只选中一本 TXT 后点击“打开章节树”，可以直接修改标题、拖拽父子关系和顺序，也能在右侧原文中选一行拆分章节。取消目录勾选只会隐藏该项的 Kindle 目录入口，正文仍会保留。数字标题如“001 雨夜”可在章节树中一键规范化为“第一章 雨夜”。

EPUB 输入只能输出 MOBI。在“MOBI 选项”中选择“保留原 EPUB 版式”可尽量维持原书排版；选择“EasyPub 兼容重排”可统一套用新版页边距、字体、CSS 等选项。固定版式 EPUB 应使用保留模式；带 DRM 的 EPUB 不支持转换。

只选中一本小说后点击“整书预览”，可以按封面、目录和全部章节检查本次真实 EPUB 排版。预览复用正式转换管线，CSS、页边距、插图和嵌入字体均会生效，但不会覆盖正式输出。

收藏目录保存在当前 Windows 用户的 `%LOCALAPPDATA%\EasyPub Modern\favorite-folders.json`；移除收藏只删除快捷记录，不会删除目录或文件。

文件夹元数据映射保存在 `%LOCALAPPDATA%\EasyPub Modern\metadata-mappings.json`；删除映射不会删除来源文件夹或其中的书稿。

MOBI 默认沿用原版行为：KindleGen 标准压缩、移除附加源文件、执行原版 EXTH 后处理。

### 为正文添加插图

1. 在文件列表中只选中一本小说，打开“插图”分页并点击“管理所选小说插图”。
2. 添加 JPG、PNG 或 WebP 图片，选中其中一张后点击“选择插入位置”。
3. 在 TXT 预览中按章节跳转、搜索或滚动到目标正文，选择一行并点击“插入在所选行之后”。
4. 保存插图设置后执行转换。原 TXT 文件不会被改写。

如果需要兼容旧工作流，也可以点“改用手动标记”，复制形如 `[[插图:夜雨]]` 的标记并让它在 TXT 中独占一行。

插图按小说分别保存，不会混入批量任务中的其他书。PNG、WebP 会保持原像素尺寸并转为高质量 JPEG，再写入 EPUB 清单或 Kindle MOBI 中间包。转换前检查会提前报告丢失或损坏的插图文件。

### 设置页边距和 CSS

展开“版式设置、页边距与定制 CSS”后，可以分别填写上、下、左、右页边距（像素）。从原版 `config.xml` 导入的页边距会显示在这里，之后可以手动覆盖。

点击“编辑 / 导入”可直接编写 CSS，也可以导入现有 `.css` 文件。CSS 内容会保存到上次设置与命名预设中，即使原 CSS 文件后来移动，已保存的样式仍然可用。定制 CSS 追加在原版样式之后，因此可以覆盖正文、标题、目录与 `.body-illustration` 插图样式。

### 嵌入字体

在“字体”分页选择独立的 `.ttf` 文件并启用嵌入。默认只保留本书实际用到的字形，可显著减小文件；复合字形依赖也会自动保留。转换前检查会读取字体嵌入许可：禁止嵌入时阻止转换，许可要求完整字体时自动完整嵌入。TTC 字体集合和 CFF/OTF 字体暂不支持。

## 批量转换 MOBI

```powershell
& 'D:\software\dotnet-sdk-10.0.302\dotnet.exe' run `
  --project 'src\EasyPub.Cli\EasyPub.Cli.csproj' -- `
  'D:\books\output' `
  'D:\books\a.txt' `
  'D:\books\b.txt' `
  --format mobi `
  --epub-mode preserve `
  --parallel 2 `
  --author '作者名' `
  --kindlegen 'C:\Users\13168\Desktop\easypub\bin\kindlegen_v2.9.exe'
```

输入顺序会被保留；多个任务的输出路径冲突会在转换前报错。

## 自定义转换效果

桌面端已开放以下选项：

| 类别 | 选项 |
|---|---|
| 文本 | 自动/UTF-8/GBK 编码、章节正则、保留空行 |
| 排版 | 字号、行高、段间距、CSS 首行缩进、对齐、原版全角缩进、四边页边距 |
| 字体 | TTF 字体许可检查、完整嵌入、按书稿实际字符子集化 |
| 样式 | 直接编辑、导入和导出定制 CSS，设置与预设保存 CSS 正文 |
| MOBI | KindleGen 路径、压缩级别、额外参数、源文件剥离 |
| EPUB 输入 | EPUB → MOBI 保留原版式或 EasyPub 兼容重排；读取目录层级、封面和正文图片 |
| 批量 | EPUB/MOBI 输出、1–4 个并发任务、统一作者 |
| 文件 | 收藏常用目录、从收藏目录多选 TXT / EPUB、每本小说独立封面、拖拽封面预览、每本小说独立正文插图 |
| 界面 | 三步式工作流、空列表引导、文件数量提示、主列表一键全选、响应式布局 |
| 检查 | 转换前检查输入、章节候选、封面、插图、字体、输出冲突与 KindleGen；双击问题可定位到对应书稿和设置 |
| 元数据 | 批量编辑每本书的标题和作者，并支持统一作者作为回退值 |
| 出版信息 | 译者、ISBN、出版日期、出版社、类别、语言和简介；ISBN/语言格式预检 |
| 预设 | 自动保存上次设置，保存、应用或删除命名转换预设 |
| 书库 | 整目录递归导入 TXT / EPUB，自动过滤已经加入的重复路径 |
| 章节树 | 标题编辑、数字标题规范化、顺序调整、拖拽层级、拆分、合并、目录包含开关、项目持久化 |
| 历史 | 保留最近 500 条成功/失败记录，载入失败项目重新转换 |
| 项目 | `.easypubproj` 保存/打开、两秒自动恢复快照、异常退出恢复 |
| 预览 | 用临时 EPUB 检查封面、目录、全部章节、CSS、页边距、插图与字体 |
| 任务 | 后台逐书进度、当前阶段、批量取消；重试保留逐书封面、插图和元数据 |

命令行还可用 `--translator`、`--isbn`、`--publication-date`、`--publisher`、`--category`、`--language`、`--description`、`--font`、`--font-family` 等参数设置同类选项。运行参数不足时会显示完整用法。

## 验证

```powershell
& 'D:\software\dotnet-sdk-10.0.302\dotnet.exe' build 'EasyPub.Modern.slnx' -c Release
& 'D:\software\dotnet-sdk-10.0.302\dotnet.exe' test 'EasyPub.Modern.slnx' -c Release
```

当前自动验证包括：

- 默认 EPUB 的 13 个内部条目与原版逐字节一致。
- 默认 MOBI 的原版调用路径、Palm 数据库结构、元数据、记录数和源文件剥离一致。
- 自定义章节正则、字号、行高、缩进、空行、四边页边距与定制 CSS 生效。
- 章节编辑、标题规范化、全选、每本小说独立封面与 WebP/PNG 无损解码转高质量 JPEG。
- 收藏目录规范化去重、重启恢复，并且移除收藏不删除原目录。
- 转换前检查、逐书元数据、设置预设、递归导入和失败任务保留/重试。
- 批量并发保持输入顺序。
- EPUB 与 MOBI 正文插图嵌入、逐书隔离、WebP/PNG 转 JPEG 和插图预检。
- 项目文件往返、恢复快照原子写入、真实 EPUB 整书预览与临时目录清理。
- TrueType 字体许可检查、字形子集、EPUB 清单/CSS 嵌入，以及字体可加载性。
- 扩展出版信息写入 OPF、XML 转义、项目文件往返，以及 ISBN/语言预检定位。
- 取消 EPUB 不覆盖已有输出；批量转换报告逐书阶段和取消状态。
- CLI 双文件并发 MOBI 和桌面端 TXT → MOBI 端到端冒烟通过。
- EPUB → MOBI 的保留版式与兼容重排均生成有效 Kindle 联合 MOBI，源 EPUB 校验值保持不变。
- 章节树重排、层级、目录排除、源文件变化失效保护和项目往返。

KindleGen 会写入运行时间等易变字段，工作目录长度也会影响内部填充，所以 MOBI 不以整个文件的 SHA-256 相等作为兼容判据。

## 当前边界

尚未完成或验证：带 DRM 的 EPUB、复杂 SVG/脚本交互内容的兼容重排、TTC/CFF 字体、单独 MOBI7/KF8、AZW3，以及原版全部高级选项组合。当前版本继续标记为预览版。

## 模块结构

- `src/EasyPub.Core`：隐藏 EPUB/MOBI 兼容细节的转换模块。
- `src/EasyPub.Cli`：可脚本化的批量入口。
- `src/EasyPub.Desktop`：WPF 桌面批量界面。
- `tests/EasyPub.Core.Tests`：黄金样本、结构与自定义选项回归测试。
- `work/easypub-compat`：分析副本、证据、脚本与黄金样本。
